This was created to facilitate running Soundbite in IIS (not IIS Express)


FILE LIST
===============================================================================
  DO NOT DELETE THESE FILES:
===============================================================================
Gen.Readme.txt         - this file
Gen.Root.ps1           - generates the root certificate authority (CA) files
Gen.Root.Request.csr   - root CA certificate signing request (CSR) config
Gen.Server.ps1	       - generates server certiicate files
Gen.Server.Request.csr - server certificate signing request (CSR) config
Gen.Server.v3.ext      - "answer file" used for fulfilling CSR
===============================================================================
  THESE ARE GENERATED BY THE SCRIPTS BUT STORED IN SOURCE CONTROL:
===============================================================================
RootCA.*               - files generated for the Root CA cert
server.*               - files generated for the web server cert
===============================================================================

NOTES:
 - CA cert must be installed in trusted root
 - Web server cert must be installed in IIS + setup with bindings for site
 - The "answer" file is what dictates the DNS + alternate DNS names. It looks
   like the DNS info is stored in the CSR but that gets discarded for some
   reason.
