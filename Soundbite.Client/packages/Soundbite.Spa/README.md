# Soundbite Client App
This document guides you through the front-end for the Soundbite App.

## Technology
This is a React 16 application originally generated by Visual Studio 2019 communnity.

That template was based on some version of [Create-React-App](https://github.com/facebook/create-react-app). Our intention is to never have to resort to ejecting the configuration.

For more information on the technologies in this application, visit the [Soundbite Wiki Tech Stack page](https://dev.azure.com/soundbiteai/Soundbite/_wiki/wikis/Soundbite.wiki/4/Tech-Stack).

## Getting Started
To start working with this application, it's as simple as:
1) From this directory, run "npm install"
2) From this directory, run "npm start"

## Deployment
To make a hosted build, simply run:
```
npm build
```

Or right-click the project and run "Build"
