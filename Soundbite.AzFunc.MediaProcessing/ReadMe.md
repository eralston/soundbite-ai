This document describes how to get started with Soundbite.AzFunc.Scheduler, which is a data loader intended for making a large volume of data for non-prod environments

# Local.Settings.Json
To get started, make a new file named `local.settings.json` in the root of this project, starting with the following credentials: https://dev.azure.com/soundbiteai/Soundbite/_wiki/wikis/Soundbite.wiki/94/Azure-Functions-local.settings.json
